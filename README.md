# Nasir Hussain — Cinematic Portfolio

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
From this folder:
```bash
python -m http.server 8000
```
Open http://localhost:8000.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — visual design, responsive layout, and animations
- `script.js` — navigation, scroll reveals, and accessible project detail dialogs
- `nasir-hero-panels-base.webp` — base hero artwork
- `hero-panel-1.png` through `hero-panel-4.png` — transparent GenAI & RAG, AWS & Cloud, Machine Learning, and Data & Analytics overlays
- `public/Nasir_2026_Resume.pdf` — current two-page resume

## Hero artwork
The hero is composed of one base WebP image with four separately positioned transparent PNG panels. The individual layers are intentional: they allow the panels to be positioned and animated independently in the layout.
